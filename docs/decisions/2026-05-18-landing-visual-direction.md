# Landing Visual Direction

Date: 2026-05-18

Decision: Use the supplied Sensual Sweets design artifacts as the visual source
of truth: dark violet canvas, HIS blue, HERS red, DUO magenta, Playfair Display,
Raleway, neon gradient borders, ambient orbs, and paired product storytelling.

Trade-off: The design brief references WebGL gummies. This implementation keeps
the first pass dependency-light by rendering the hero product stage with
code-native layered pouches and gummy forms instead of adding Three.js/R3F. The
visual system still preserves the dual-product hero, ambient glow, and webshop
conversion path, while leaving room to replace the stage with WebGL assets later.
