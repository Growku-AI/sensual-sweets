# Changelog format (Keep a Changelog)

```
## [version] - YYYY-MM-DD

### Added
- …

### Changed
- …

### Fixed
- …

### Removed
- …
```

Rules:
- Newest version on top.
- ISO dates (`YYYY-MM-DD`).
- One bullet per user-facing change, written for humans (not raw commit subjects).
- Skip empty groups.
- Keep compare links at the bottom of the file: `[1.2.0]: https://…/compare/v1.1.0...v1.2.0`.
